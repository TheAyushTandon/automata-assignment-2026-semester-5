1 Define the Machine — Core Automata Concepts

Section 1 Overview

Standard Finite Automata (like DFAs and NFAs) are decision makers: they read a string of symbols and give a single binary verdict at the end—either ACCEPT or REJECT.

Finite State Machines with Output (Transducers) do something much more useful: instead of just saying yes or no, they generate a sequence of output symbols as they read input symbols. They are the fundamental blueprint behind digital logic circuits, serial communication protocols, lexical analyzers, and hardware controllers.

The Formal 6-Tuple Definition

Both Mealy and Moore machines are formally defined by a mathematical 6-tuple:

Mathematical Definition M = (Q, Σ, Δ, δ, λ, q₀)
  • Q (Set of States): A finite set of states representing the machine's internal memory (e.g., {q1, q2, q3, q4}).
  • Σ (Input Alphabet): A finite set of symbols the machine can read from the outside world (e.g., {0, 1}).
  • Δ (Output Alphabet): A finite set of symbols the machine can produce and transmit (e.g., {0, 1} or {A, B}).
  • δ (Transition Function): The roadmap of the machine. It takes the current state and an input symbol, and specifies which state to move to next:
    δ : Q × Σ → Q
  • λ (Output Function): The rule that dictates what output is generated. This is the only structural difference between Mealy and Moore machines!
  • q₀ (Start State): The designated initial state where computation begins (q₀ ∈ Q).

Mealy vs. Moore: Where Does the Output Live?

Mealy Machine

Output lives on the transitions (arrows).

λ : Q × Σ → Δ

The output depends on both the current state and the incoming input symbol. Think of typing on a keyboard: the character printed on screen depends on which state your computer is in and which key you just tapped.

Moore Machine

Output lives inside the states (nodes).

λ : Q → Δ

The output depends strictly on the state you are in, regardless of how you got there. Think of a room with a lightbulb: the color of light in the room depends solely on which room you entered, not which doorway you walked through.

Fig 1. Hand-drawn doodle comparison: Mealy places outputs on transitions, Moore binds outputs to state memory.

Input Table & Robust Validation

When you enter state names and alphabet symbols in Section 1, the simulator immediately dynamically generates a matrix where every combination of (state, input) has an exact cell for next-state and output.

Before running any conversions, the validator guarantees mathematical integrity:

  • Checks that every state has transitions defined for all input alphabet symbols (deterministic and complete).
  • Validates that transition targets belong to the defined set of states Q.
  • Verifies that output values strictly belong to the output alphabet Δ.
  • Guarantees the start state q₀ is an existing state.

2 Step-by-Step Conversion — Algorithms & Math

Section 2 Overview

Can every Mealy machine be converted into an equivalent Moore machine, and vice-versa? Yes! They have identical computational power. However, their internal wiring must be converted systematically.

2.1 Mealy → Moore Conversion (The State-Splitting Method)

The Problem: In a Mealy machine, state q2 might be entered from q1 producing output 0, and also entered from q3 producing output 1. Because a Moore machine requires every state to possess a single fixed output, state q2 faces a contradiction.

The Solution: We duplicate ("split") the state! We create a copy of q2 for output 0 (named q2_0) and another copy for output 1 (named q2_1).

State Splitting Rule: A Mealy state q is split into as many Moore states as there are unique output symbols on transitions entering q.

The 4-Step Algorithmic Pipeline

  1. Step 1 — Collect Incoming Outputs: For every state q ∈ Q, examine all transitions entering q and collect the set of outputs O(q):
    Incoming Outputs Set O(q) = { λ(p, a) ∣ p ∈ Q, a ∈ Σ, δ(p, a) = q }
    Edge Case: If a state has no incoming transitions (like an isolated start state), O(q) is empty. We assign it any arbitrary symbol from Δ so it receives a valid Moore state output.
  2. Step 2 — Create Split Moore States: For each state q and each output o ∈ O(q), create a new Moore state pair ⟨q, o⟩ (displayed as q_o in the UI).
    New States & Outputs Q' = { ⟨q, o⟩ ∣ q ∈ Q, o ∈ O(q) }
    λ'(⟨q, o⟩) = o
  3. Step 3 — Wire the Transitions: Every clone ⟨q, o⟩ behaves on future inputs just like the original state q. When it reads input a, it transitions to the copy of δ(q, a) whose designated output matches λ(q, a):
    Moore Transition Function δ'(⟨q, o⟩, a) = ⟨δ(q, a), λ(q, a)⟩
  4. Step 4 — Designate the Start State: The new start state is simply the copy of the original start state ⟨q₀, o⟩.
Worst-Case State Bound |Q'| ≤ |Q| × |Δ|

For a binary alphabet where |Δ| = 2, a 4-state Mealy machine will produce at most 4 × 2 = 8 Moore states. In our classic 4-state example, only two states receive conflicting outputs, resulting in exactly 6 Moore states.

Fig 2. State Splitting Doodle: When multiple incoming transitions have different outputs, the state duplicates into specialized output copies.

2.2 Moore → Mealy Conversion (The Output-Shifting Method)

Converting from Moore to Mealy is much simpler because no state splitting is ever needed. Every Moore state already has an unambiguous, pre-assigned output.

When a transition is taken from state q to state p, the machine enters p. Since Moore output is emitted whenever a state is entered, we simply move the output of destination state p directly onto the transition arrow!

Moore to Mealy Shift Formula Q' = Q,   q₀' = q₀,   δ'(q, a) = δ(q, a)
λ'(q, a) = λ(δ(q, a))

Explanation: The output for transition (q, a) becomes the output of the state you land on (λ(target)). The state count remains exactly the same: |Q'| = |Q|.

Fig 3. Output Shifting Doodle: The destination state's output shifts backwards onto the incoming transition.

2.3 State Minimization (Removing Unreachable & Merging Equivalent States)

State splitting can create extra states that are never visited from the start state, or states that act as exact twins. When "Minimize result" is checked, the simulator executes a rigorous two-phase minimization:

  1. Phase 1 — Reachability Analysis (BFS): Starting at initial state q₀, we traverse all transitions using Breadth-First Search. Any state not reachable from q₀ is permanently pruned from the machine.
  2. Phase 2 — Partition Refinement (Hopcroft / Moore Reduction): Two states p and q are equivalent (p ≡ q) if they produce identical outputs for every possible input string from that point onward.
    • Base Partition (P₀): Group states by their immediate output behavior. For Moore machines, states with the same λ(q) share a block. For Mealy machines, states with identical output vectors λ(q, ·) share a block.
    • Refinement Step: For every block of states B and every input symbol a ∈ Σ, check where the transitions lead. If state p ∈ B transitions to block X while state q ∈ B transitions to block Y (where X ≠ Y), then p and q are distinguishable! Block B is split.
    • Stabilization: We repeat this check until no block can be split any further. Each final block represents a single unified state in the minimal machine.

3 Simulate & Validate — The "Length Off-by-One" Law

Section 3 Overview

Section 3 allows you to test any string w on both machines simultaneously and inspect the step-by-step internal state transitions, output symbols, and equivalence verdicts.

The "Off-by-One" Length Difference

A common source of confusion in automata theory is why the output lengths of Mealy and Moore machines differ for the exact same input string:

Mealy Output Length

|output| = |w|

An output is emitted only when taking a transition. For an input of length 4 (e.g. 0011), exactly 4 transitions are taken, producing an output of length 4 (e.g. 0100).

Moore Output Length

|output| = |w| + 1

A Moore machine emits the output of its initial state λ(q₀) at time 0, before reading any input! After taking 4 transitions, it has visited 5 states, producing an output of length 5 (e.g. 1 0100).

The Equivalence Theorem

Equivalence Formula Moore(w) = λ(q₀) · Mealy(w)

A Mealy machine M₁ and Moore machine M₂ are equivalent if and only if for every input string w, the Moore output is equal to the initial state's output λ(q₀) concatenated with the Mealy output.

Verification Rule: In the simulator, Moore output is compared against Mealy output by dropping the leading λ(q₀) symbol. If the remaining substrings match for all inputs, the conversion is 100% equivalent!

Fig 4. The Equivalence Rule: Moore outputs emit an extra symbol at t=0. Once trimmed, outputs match identically.

Exhaustive Equivalence Verification

Manual testing only checks individual strings. The Exhaustive Equivalence Checker systematically generates every possible combination in the input language up to length L:

Exhaustive String Set Strings Tested = ∑ (from k=0 to L) |Σ|ᵏ

For a binary alphabet Σ = {0, 1} up to length L = 8, the engine synthesizes and validates all 1 + 2 + 4 + 8 + 16 + 32 + 64 + 128 + 256 = 511 strings in a single pass in under 5 milliseconds, proving formal equivalence beyond any doubt.

4 Under the Hood — Graph Layout & Animation Engine

Rendering Architecture

The diagrams in this simulator are rendered via dynamic inline SVG with custom layout geometry, physics dragging, and smooth path interpolation:

1. Circular Trigonometric Coordinate Layout

Given a machine with N states, states are automatically distributed uniformly around an ellipse or circle centered at (x_c, y_c) with radius R:

Node Coordinate Formula θ_i = (2π · i / N) - π/2
x_i = x_c + R · cos(θ_i),   y_i = y_c + R · sin(θ_i)

Offsetting by -π/2 positions the first state directly at 12 o'clock (the top), preserving visual hierarchy.

2. Quadratic Bézier Curve Offsetting

When transitions exist in both directions between state A and state B (i.e. A → B and B → A), drawing straight lines would cause the arrows to overlap and obscure each other.

The engine calculates the unit normal vector N = (-dy/len, dx/len) perpendicular to the line connecting A and B, and displaces the control point C by an offset proportional to the distance:

Quadratic Bézier Curve Equation B(t) = (1 - t)² · A + 2(1 - t)t · C + t² · B   (for t ∈ [0, 1])

3. Smooth 2-Second Transition Line Animation

Instead of wiping and re-drawing the entire diagram on every step, the rendering engine preserves past states and edges in clean solid grey. Only the active orange transition arrow animates:

  • Calculates the precise curve path length using path.getTotalLength().
  • Initializes SVG strokeDasharray = len and strokeDashoffset = len (the line is completely retracted).
  • Executes a 2-second (2000ms) Web Animations API transition easing from strokeDashoffset: len to 0 using cubic-bezier(0.35, 0.05, 0.25, 1).
  • The moment the line touches the target state circle, the arrowhead marker snaps into place, producing a natural, fluid pen-draw effect.
